🚀 Getting Started
Prerequisites
Git

Node.js (if using a JS-based static site generator)

Ruby (if using Jekyll)

Local Development
bash
# Clone the repository
git clone https://github.com/dipankar1055-sketch/neelkanthsphuta-website.git
cd neelkanthsphuta-website

# If using Jekyll
bundle install
bundle exec jekyll serve

# If using Node-based SSG (e.g., Next.js, Astro)
npm install
npm run dev
Open http://localhost:4000 (Jekyll) or the port indicated by your dev server.

🌐 Deployment
GitHub Pages
Push to main branch.

Go to Settings → Pages.

Set source to main branch, root folder.

Enforce HTTPS.

Add custom domain: neelkanthsphuta.ai.

Netlify / Vercel
Connect the repository, set build command and publish directory, and deploy.
Add custom domain neelkanthsphuta.ai.
